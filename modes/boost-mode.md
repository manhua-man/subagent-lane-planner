# Mode: /boost (Deeper Investigation and Review)

Use for `/boost`, deeper investigation, or stronger verification. Apply the [main task loop](../SKILL.md#auxiliary-command-modes).

- Follow evidence wherever needed: across modules, layers, dependencies, or competing hypotheses. Use reproduction, diagnostic edits, experiments, and implementation in the order that best resolves uncertainty.
- Challenge important assumptions and review plausible failure cases. Select the depth and methods that fit the problem rather than completing a universal checklist.
- Use findings to improve the requested result and verify material corrections. Investigation breadth is a reasoning choice; additional unrelated changes remain a separate scope decision.
- Deliver the fidelity the user requested. For analysis, review conclusions and counterexamples; for implementation, verify behavior with useful checks. Report material uncertainty that remains.
