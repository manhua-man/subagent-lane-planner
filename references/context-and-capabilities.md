# Context and Capabilities

Use the main conversation to retain task understanding while choosing the knowledge, tools, and context arrangement that best support the next action.

## Find useful knowledge

Start with available skill descriptions and tool discovery. Read selected procedures and project instructions as required, then follow supporting resources as the investigation warrants. Use parallel calls, focused reads, broader exploration, or external contexts according to their value.

Reuse relevant sources and summarize noisy output when useful; expand the evidence read when a summary is insufficient to make the decision.

## Retain what enables progress

For a long task or context handoff, keep a short record in the host's existing task mechanism. Useful contents include:

- The current goal and relevant user decisions.
- Established facts, evidence locations, and actual verification.
- Pending work, active writers, assumptions, and the next useful action.

Choose the format and detail needed to resume reliably. Small tasks may need no saved record.

## Adapt and resume

When the user redirects the task or evidence changes an assumption, reconcile affected work and update the next action. On resumption, compare retained context with current files and pending results, rechecking anything consequential that became stale.

Use the host's available memory, execution, and continuation capabilities. State what was actually retained or resumed and what remains pending.
