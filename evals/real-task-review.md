# 真实任务评测提示词

完成一次真实任务后，在执行该任务的原对话中粘贴下面这段话，让智能体依据已有执行记录复盘。

```text
评测这次 subagent-lane-planner 的实际表现。根据执行记录，检查验收结果、模型分工、并行收益、越界、重复劳动和返工。给出证据，并判断哪些委派值得保留、哪些应该主线程完成。缺失的耗时或 token 数据标为未知，不要推算。
```

如果换了对话，请同时提供原任务需求和可用的执行记录；仅有最终总结时，应明确评测受限。

复盘结果可按以下项目记录，便于比较多次真实任务：

| 项目 | 记录内容 |
|---|---|
| 任务与验收 | 原始目标、实际结果、验证证据与未完成项 |
| 模型分工 | 主线程和各子任务的实际模型、推理强度与工作范围 |
| 并行收益 | 独立推进的证据、等待依赖的情况；无对照时不声称节省了多少时间 |
| 边界与重复劳动 | 越界、嵌套委派、重复调查或主线程重做的具体记录 |
| 返工与回退 | 失败原因、修正或换模型的依据、是否解决问题 |
| 耗时与用量 | 仅记录可核实数据；缺失项标为未知，不推算 |
| 后续调整 | 哪些委派保留，哪些交给主线程；每项附证据 |

单次复盘用于发现问题，不能证明比禁用 Skill 更快或更省。需要对照评测时，使用 [行为回放与统计口径](cases.md)。
