# 真实任务评测提示词

在完成或明确阻塞的原任务对话中粘贴：

~~~text
评测这次 subagent-lane-planner 的实际表现。重点看主会话是否始终掌握最新目标，是否依据真实结果调整行动并推进到验收，而不只是生成计划、派工和汇总。根据执行记录检查按需加载、需求变化、上下文续接，以及外部结果如何改变下一步。区分直接工具调用、临时子代理与独立会话，核对权限、实际产物、未完成项和验证证据。给出具体证据与需要保留或收敛的规则；缺失耗时、用量或轨迹时标为未知，不要推算。
~~~

如果换了对话，请提供原始需求及变更、可用执行记录和实际产物；仅有最终总结时明确评测受限。不要把主会话更长、代理更多或更少当作收益。

| 项目 | 核对内容 |
|---|---|
| 最新目标与结果 | 是否按最新约束交付，哪些必要项仍未完成 |
| 主会话推进 | 哪条证据改变了哪一步行动，是否只有计划更新而无实际推进 |
| 能力加载 | 哪些规则、参考或工具按需使用，是否重复或过量读取 |
| 外部结果 | 使用何种执行者、适用基线和合同，回传如何核验并接入下一步 |
| 连续性 | 新需求或上下文续接后是否丢失决定，是否接受过期或重复结果 |
| 边界与恢复 | 越域、未确认停写、错误重发、盲目升级模型或扩大范围 |
| 验收与用量 | 实际检查及限制；只记录可核实耗时、逐线程模型/推理设置与用量 |
| 后续调整 | 保留、收敛或撤销哪些规则，每项依据是什么 |

单次复盘用于发现问题，不能证明新版比旧版或原生执行更快、更省。固定条件重复对照见 [回放与统计口径](cases.md)。
