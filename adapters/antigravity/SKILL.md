# Antigravity Command Modifiers

Activate on-demand when user requests:
- `/goal`: Enforce autonomous loop with exit-code-0 verification and self-healing. See `modes/goal-mode.md`.
- `/boost`: Enforce specialized routing and adversarial edge-case review. See `modes/boost-mode.md`.
- `/teamwork`: Enforce orthogonal decomposition, single-writer protection, and consolidation. See `modes/teamwork-mode.md`.
